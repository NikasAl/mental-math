## 2. Детальная спецификация экранов

### 2.1 Splash Screen

**Маршрут:** `/`

**Назначение:** Проверка авторизации и загрузка начальных данных

**Логика:**
```
1. Проверка токена в SecureStorage
   ├─ Токен есть → get_me()
   │   ├─ Успех → MainShell
   │   └─ Ошибка → device_login() → MainShell
   └─ Токена нет → device_login() → MainShell
```

**UI:**
```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│           🧮 ЛЕЖАНДР               │
│                                     │
│        MindVector Client           │
│                                     │
│         [Loading indicator]         │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

### 2.2 Main Shell (Bottom Navigation)

**Маршрут:** `/main`

**Структура:**
```dart
ShellRoute(
  builder: (context, state, child) => MainShell(child: child),
  routes: [
    GoRoute(path: 'home', builder: ...),
    GoRoute(path: 'library', builder: ...),
    GoRoute(path: 'statistics', builder: ...),
    GoRoute(path: 'profile', builder: ...),
  ],
)
```

**Bottom Navigation Items:**
| Index | Icon | Label | Badge |
|-------|------|-------|-------|
| 0 | 🏠 home | Дом | — |
| 1 | 📚 library_books | Библиотека | Активные задачи |
| 2 | 📊 bar_chart | Статистика | — |
| 3 | 👤 person | Профиль | — |
